# Quant Research Lab

A Python quantitative finance project analyzing SPY market data.

## What This Project Does

This project compares:

- Buying and holding SPY
- A 20-day/50-day moving-average trading strategy

## Analysis Included

- Daily returns
- Moving averages
- Trading signals
- Cumulative returns
- Volatility
- Sharpe ratios

## Tools Used

- Python
- pandas
- yfinance
- matplotlib

## How to Run

Install the required packages:

```bash
pip install yfinance pandas matplotlib
